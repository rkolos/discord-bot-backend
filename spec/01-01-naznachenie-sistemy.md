# 1.1. Назначение системы

## Описание продукта

**Server.Ninja** — это платформа для управления Discord-ботами, предоставляющая комплексные инструменты для аналитики и мониторинга Discord серверов (гильдий).

### Основные возможности системы:

1. **Управление Discord-ботами**
   - Подключение и управление несколькими Discord ботами
   - Мониторинг состояния ботов и шардов
   - Управление конфигурацией ботов

2. **Аналитика и статистика**
   - Сбор и анализ событий из Discord серверов
   - Визуализация активности пользователей
   - Генерация отчётов и дашбордов
   - Heatmap активности
   - Leaderboard (рейтинги участников)

3. **Система каунтеров (Live Counters)**
   - Создание и управление счётчиками для Discord каналов
   - Типы счётчиков:
     - **Stat** — статистические счётчики (количество участников, онлайн и т.д.)
     - **Goal** — счётчики целей (прогресс к определённой цели)
     - **Clock** — временные счётчики (отображение времени)
   - Автоматическое обновление названий каналов на основе агрегированных данных

4. **Виджеты (Widgets)**
   - Создание виджетов для отображения статистики
   - Встраивание виджетов на внешние сайты

5. **Управление командами (Teams)**
   - Совместная работа над гильдиями
   - Управление правами доступа участников команды

6. **Система биллинга**
   - Управление подписками (Free, Pro, Enterprise)
   - Отслеживание лимитов использования
   - Управление биллингом компаний

## Архитектура API сервисов

Система состоит из **двух отдельных API сервисов**, реализованных как независимые NestJS приложения:

### Frontend API Service

**Назначение:** Публичный API для взаимодействия с фронтенд приложением

**Характеристики:**
- Доступен из интернета
- Обрабатывает запросы от пользовательского интерфейса
- Реализует функциональность для конечных пользователей:
  - Аутентификация через Discord OAuth2
  - Управление гильдиями и командами
  - Просмотр аналитики и статистики
  - Управление каунтерами и виджетами
  - Управление настройками серверов
  - Работа с биллингом

**Базовый URL:** Настраивается через переменные окружения (по умолчанию `/api`)

**Документация:** См. `ABOUT/API_SPEC_FRONT/`

### Admin API Service

**Назначение:** Административный API для внутреннего управления системой

**Характеристики:**
- **Закрыт под VPN** — доступен только через VPN соединение
- **Недоступен из интернета** — развёрнут в приватной сети
- Используется администраторами для:
  - Мониторинга состояния системы
  - Управления пользователями (бан, разбан, импersonation)
  - Управления гильдиями
  - Просмотра системной аналитики
  - Мониторинга шардов и очередей
  - Управления логами системы

**Базовый URL:** Настраивается через переменные окружения (по умолчанию `https://api.server.ninja`)

**Документация:** См. `ABOUT/API_SPEC_ADMIN/`

### Общие компоненты

Оба API сервиса используют общие инфраструктурные компоненты:

- **PostgreSQL** — транзакционная база данных
- **ClickHouse** — аналитическая база данных (OLAP)
- **Redis** — кэш и брокер сообщений
- **Bot Service** — сервис для взаимодействия с Discord Gateway
- **Ingestor Worker** — воркер для переноса данных из Redis в ClickHouse
- **Background Worker** — воркер для обработки фоновых задач (BullMQ)

## Целевая аудитория

1. **Владельцы Discord серверов** — для управления своими серверами и получения аналитики
2. **Администраторы серверов** — для мониторинга активности и настройки каунтеров
3. **Разработчики** — для интеграции виджетов и API в свои проекты
4. **Администраторы платформы** — для управления системой через Admin API
