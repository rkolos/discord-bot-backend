# Команда /коммит

Выполни следующую последовательность. Не прерывай её и не делай коммит/пуш без успешного прохождения всех проверок.

## 1. Проверка кода на ошибки

1. **Линтинг:** выполни `npm run lint`. При наличии ошибок ESLint — исправь их (например, через `npm run lint:fix`) или сообщи пользователю и остановись; коммит не создавать.
2. **Тесты:** выполни `npm run test`. При падении тестов — исправь или сообщи пользователю и остановись; коммит не создавать.
3. **Проверка типов:** выполни `npm run typecheck`. При ошибках TypeScript — сообщи пользователю и остановись; коммит не создавать.
4. **Сборка:** выполни `npm run build`. При ошибках сборки (NestJS/TypeScript) — сообщи пользователю и остановись; коммит не создавать.

Либо выполни одну команду `npm run precommit-check` (она по очереди запускает lint, test, typecheck и build). При любом ненулевом коде выхода — остановись и не переходи к коммиту.

## 2. Подготовка коммита и пуш

Только если все шаги из п. 1 завершились успешно:

1. Выполни `git status` и посмотри список изменённых/новых/удалённых файлов.
2. По содержимому изменений (например, `git diff`, `git diff --staged`, при необходимости `git diff --name-only`) сформируй **подробное сообщение коммита** на русском языке:
   - первая строка — краткий заголовок (до ~72 символов), в формате типа `feat(область): что сделано` или `fix(область): что исправлено`;
   - затем пустая строка и описание: что именно изменено/добавлено/удалено, по каким файлам или модулям, без лишнего кода в сообщении.
3. Выполни:
   - `git add` для файлов, которые должны войти в коммит (как правило, все изменённые в рамках задачи, без лишнего — не добавлять `.env` с секретами, артефакты сборки и т.п.);
   - `git commit -m "<заголовок>" -m "<описание>"` с подготовленным текстом;
   - `git push` (в текущую ветку, например `origin develop`).

Если нечего коммитить (`nothing to commit`), сообщи об этом и пуш не выполняй.

## 3. Итог

После успешного пуша кратко подтверди: что проверено (lint, test, typecheck, build), что закоммичено и в какую ветку выполнен пуш.
